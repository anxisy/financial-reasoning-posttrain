# ConvFinQA answer-only self-generated history v1

This is an **additive patch** for the existing `/root/autodl-tmp/ConvFinQA/` repository. It does not change existing SFT adapters, oracle-history predictions or training data. Do NOT remove your current project directories.

## What gets compared

- `matched_oracle`: ground-truth previous answers, but a neutral `Previous conversation:` prompt header.
- `model_answer_history`: each turn receives the *same model's own preceding extracted final answers*; no current or future gold is passed to its prompt.
- Both use the identical neutral header, so the matched comparison isolates the effect of preceding answer content rather than changing prompt headers.
- This is **answer-only self-history**, not full assistant transcript free-running; it matches the SFT history format and tests answer-error propagation. Use a separate full-transcript evaluation if desired.
- Inputs are ConvFinQA Dev (1490 turns, 421 conversations), same frozen scorer as initial Baseline. Pairwise intervals resample conversation IDs.

## Installation on AutoDL

Upload `convfinqa_self_history_v1.zip` to `/root/autodl-tmp/`, then:

```bash
cd /root/autodl-tmp
unzip -o convfinqa_self_history_v1.zip
source /root/autodl-tmp/open-r1/19_vllm_benchmark/.venv/bin/activate
export VLLM_USE_FLASHINFER_SAMPLER=0
export OMP_NUM_THREADS=8
export MKL_NUM_THREADS=8
cd /root/autodl-tmp/ConvFinQA
```

Smoke test, 5 COMPLETE conversations, both models:

```bash
python 00_common/eval_self_history_v1.py --variants transfer,direct --max-conversations 5
```

Full evaluation, 421 COMPLETE conversations:

```bash
python 00_common/eval_self_history_v1.py --variants transfer,direct --max-conversations 0
```

**Important**: Smoke and full run default to the same output folder. After smoke, run full only after validation; full will overwrite smoke files, or use distinct `--output-dir` for smoke.

Outputs:

```text
/root/autodl-tmp/project/convfinqa_posttrain/experiments/convfinqa_sft_v2/self_history_v1/
    transfer/matched_oracle/metrics.json
    transfer/model_answer_history/metrics.json
    transfer/oracle_vs_self_paired.json
    direct/matched_oracle/metrics.json
    direct/model_answer_history/metrics.json
    direct/oracle_vs_self_paired.json
    self_history_transfer_vs_direct.json
    run_config.json
```

Compare the two `matched_oracle` results to the prior frozen Oracle measurements; they can differ somewhat because this v1 deliberately uses a neutral header in both modes. Only the *within-v1 matched comparison* cleanly isolates the self-answer-history change.

Warnings: `model_answer_history` propagates extracted answer strings (`prediction_answer`), not complete assistant reasoning. If extraction finds no answer it propagates `[NO_ANSWER]`, never gold. The history is gold-free for prior turns except numbers already present in financial text and independently generated by the model.
